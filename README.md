# 拾词 (Shici - English Word Extractor)

一键提取网页英文单词的 Chrome 扩展，用于词汇背诵。

## 功能特点

- **一键提取**：提取当前页面所有英文单词（3字母以上），自动去重、排序
- **智能过滤**：自动跳过已收录词汇，显示「词袋已有」数量
- **连续天数**：追踪每日使用，激励持续学习习惯
- **本周统计**：动态显示本周新增词汇，每周自动重置
- **词袋管理**：我的词袋页面管理已收录词汇，支持添加、上传、导出、清空
- **批量粘贴**：输入框支持换行/空格/逗号分隔的多词粘贴
- **一键导出**：复制或下载 TXT 文件，支持「不背单词」等 APP 导入

## 安装

1. 从 Chrome Web Store 安装
2. 或手动安装：下载源码 → Chrome 托管扩展 → 加载已解压的扩展程序 → 选择 `src/` 目录

## 使用流程

1. 打开任意英文网页
2. 点击扩展图标 → 点击「拾起本页生词」
3. 查看新词和「词袋已有」数量
4. 点击「复制并加入词袋」或「下载 TXT」
5. 复制/下载后词汇自动入袋，下次提取自动跳过

## 词袋管理

- 点击弹窗底部「我的词袋」进入管理页面
- 查看已拾起词汇总数、连续天数、本周新增
- 输入框快速添加单词，支持批量粘贴
- 上传 TXT 文件批量导入
- 导出备份、清空词袋

## 权限说明

- `activeTab`: 仅在用户点击扩展图标时访问当前标签页
- `scripting`: 动态注入脚本提取单词
- `storage`: 本地存储已收录词汇和统计数据

**隐私声明**: 不收集任何用户数据，完全本地运行。
