# 生词提取器 (English Word Extractor)

一键提取网页英文单词的 Chrome 扩展，用于词汇背诵。

## 功能特点

- 一键提取当前页面所有英文单词（3字母以上）
- 自动去重、转小写、按字母排序
- 实时预览提取结果
- 一键复制或下载 TXT 文件
- 支持「不背单词」等背词 APP 导入

## 安装

1. 从 Chrome Web Store 安装（审核中）
2. 或手动安装：下载源码 → Chrome 托管扩展 → 加载已解压的扩展程序

## 权限说明

- `activeTab`: 仅在用户点击扩展图标时访问当前标签页
- `scripting`: 动态注入脚本提取单词

**隐私声明**: 不收集任何用户数据，完全本地运行。
