# 已收录词汇功能规格文档

## 背景

用户使用扩展从网页提取英文单词导入背词 APP。存在以下问题：
1. 不同页面可能有重复单词，导致导入 APP 后重复学习
2. 卸载扩展后数据丢失，无法恢复
3. 用户已掌握的单词仍会被提取，浪费时间

## 目标

实现「已收录词汇」功能，统一管理用户已掌握和已提取过的单词，后续提取时自动过滤。

## 功能需求

### F1: 词汇存储

- 使用 `chrome.storage.local` 存储
- 数据结构：Set（JSON 序列化存储，查找时反序列化为 Set）
- 存储键名：`collectedVocabulary`
- 容量：chrome.storage.local 5MB，足够存储数万单词

### F2: Options 页面

- 新建独立的 `options.html` 页面
- manifest.json 声明 `options_page`
- popup 保持简洁，添加「管理词汇」链接跳转到 options 页面

### F3: 词汇管理功能

**导入词汇**
- 文本框粘贴导入：支持换行分隔的单词列表
- 文件导入：上传 txt 文件，换行分隔
- 导入前校验：过滤非 3+ 字母英文单词，转小写

**添加单个词汇**
- 输入框输入单个单词
- 添加按钮触发
- 校验：必须是 3+ 字母英文单词，转小写

**导出备份**
- 下载为 txt 文件，换行分隔
- 文件名格式：`collected_vocabulary_YYYY-MM-DD.txt`

**清空词汇**
- 一键清空按钮
- 弹出确认提示：「确定清空所有已收录词汇？此操作不可恢复」

**词汇列表展示**
- 显示已收录词汇总数
- 可滚动列表展示所有词汇
- 每个词汇旁有删除按钮（单个删除）

### F4: 提取流程改动

**过滤逻辑**
- 提取网页单词后，过滤掉已收录词汇中的单词
- 过滤在 popup.js 中执行（获取已收录词汇后本地过滤）

**自动收录**
- 用户导出单词后，自动将导出的单词加入已收录词汇
- 弹出提示：「已将 X 个单词加入已收录词汇」

### F5: 备份提醒（可选）

- 当已收录词汇超过 100 个时，在 options 页面顶部显示提醒：「建议定期导出备份，卸载扩展后数据将丢失」

## 非功能需求

### N1: 性能

- 词汇查找使用 Set，O(1) 时间复杂度
- 词汇数量在 10000 以内时，列表渲染无明显延迟

### N2: 兼容性

- 支持 Chrome 88+（Manifest V3）
- 与现有提取功能无冲突

### N3: 数据安全

- 导入词汇前校验格式，防止恶意数据
- 清空操作需二次确认

在底部添加链接：

```

│  [提取单词]                         │

```

```
src/
├── manifest.json     (修改：添加 options_page)
├── popup.html        (修改：添加管理链接)
├── popup.js          (修改：添加过滤逻辑、自动收录逻辑)
├── popup.css         (修改：添加链接样式)
├── options.html      (新建)
├── options.js        (新建)
├── options.css       (新建)

```

## 依赖关系

- `vocabulary.js`：词汇存储核心逻辑，被 popup.js 和 options.js 共享
- `options.js`：依赖 vocabulary.js
- `popup.js`：依赖 vocabulary.js（过滤、自动收录）
